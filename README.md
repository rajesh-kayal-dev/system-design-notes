# System Design

A collection of system design notes, architecture concepts, and practical projects to build a strong understanding of designing scalable and reliable software systems.

## Topics

| Folder | Description |
|---|---|
| [Fundamentals](./01-fundamentals/) | Core concepts, networking, APIs, and databases |
| [Components](./02-components/) | Caching, Redis, load balancers, message queues, and CDN |
| [Architecture](./03-architecture/) | Scalability, reliability, and architecture patterns |
| [System Design Problems](./04-system-design-problems/) | Design solutions for real-world applications |
| [Projects](./05-projects/) | Practical implementations of system design concepts |
| [Interview Questions](./06-interview-questions/) | Common interview questions and revision notes |

## Goals

- Understand system design concepts from the basics.
- Learn how different components work together.
- Practice designing real-world applications.
- Understand architectural decisions and trade-offs.
- Prepare for system design interviews.

## Tech Stack

Node.js, Express.js, MongoDB, PostgreSQL, Redis, Kafka, Docker, and other technologies as needed.

## Progress

This repository is continuously updated as I learn new concepts and build projects.
