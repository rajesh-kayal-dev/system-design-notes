# System Design

A collection of beginner-friendly system design notes and practical projects to help me understand how to design scalable and reliable software systems.

## Topics

| Folder | Description |
|---|---|
| [Fundamentals](./01-fundamentals/) | Core concepts, networking, APIs, and databases |
| [Components](./02-components/) | Caching, Redis, load balancers, message queues, and CDN |
| [Architecture](./03-architecture/) | Scalability, reliability, availability, and architecture concepts |
| [Design Patterns](./04-design-patterns/) | Timeout, retry, circuit breaker, idempotency, event-driven architecture, API gateway, cache-aside, and Saga |
| [Projects](./05-projects/) | Practical system design practice, with one folder per project and diagrams |
| [Interview Questions](./06-interview-questions/) | Common interview questions, revision notes, and trade-offs |

## How I Practise

Each project has its own folder with a main README and a `diagrams/` folder. I start with a simple architecture, explain how it works, and then improve it only when an interviewer introduces a new requirement, such as higher traffic or faster responses.

## Goals

- Understand system design concepts from the basics.
- Learn how components work together.
- Practise designing and explaining real-world applications.
- Understand architectural decisions and trade-offs.
- Prepare for system design interviews through step-by-step project practice.

## Technologies

Node.js, Express.js, MongoDB, PostgreSQL, Redis, Kafka, Docker, and other technologies when they are useful for a project.

## Progress

This repository is continuously updated as I learn concepts and practise system design through projects.
